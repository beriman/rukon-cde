# 📥 Handoff Template

Jika seorang agen (misal: Dev) perlu mendelegasikan tugas ke agen lain (misal: QA), salin template ini dan buat file baru di folder `inbox/` dengan nama format: `[TargetAgent]_[TaskName]_[Date].md`.

```markdown
**To**: [Agent Protocol/Name, e.g., QA / Quinn]
**From**: [Your Protocol/Name, e.g., Dev / James]
**Date**: YYYY-MM-DD
**Priority**: [High / Medium / Low]

## Task Request
[Deskripsi spesifik tentang apa yang harus dilakukan agen target]

## Relevant Context
- [File yang perlu dicek: e.g., `docs/stories/epic-1/story-1.1.md`]
- [Script yang bisa digunakan: e.g., `execution/quality_dashboard.py`]

## Expected Output
[Apa yang diharapkan dari agen target]
```
