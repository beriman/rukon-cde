## 2024-05-30 - Path Traversal via Unsanitized `file.originalname` in File Uploads
**Vulnerability:** Path traversal vulnerability due to using the untrusted `file.originalname` directly inside `path.join` and S3 object keys (in `FilesService` and `SiteCaptureService`). Even if a timestamp or UUID is prepended, `path.join('dir', \`\${id}-\${file.originalname}\`)` will traverse directories if `file.originalname` contains sequences like `a/../../etc/passwd`, leading to arbitrary file writes or overwriting outside the intended directory.
**Learning:** Node.js path manipulation methods and S3 key constructions are susceptible to directory traversal when concatenating a prefix with an unsanitized untrusted string containing directory separators.
**Prevention:** Always sanitize `file.originalname` (or any untrusted file name) by extracting the base name via `path.basename(file.originalname)` and subsequently stripping unsafe characters using a regex like `.replace(/[^a-zA-Z0-9.\-_]/g, '_')` before appending it to prefixes or passing it to `path.join()`.
