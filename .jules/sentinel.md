## 2024-05-24 - [Unauthenticated API Endpoints in Construction Module]
**Vulnerability:** Several controllers in `apps/api/src/construction` (e.g., `construction.controller.ts`, `submittal.controller.ts`, `claim.controller.ts`, `procurement.controller.ts`) were missing authentication guards, leaving sensitive construction-related API endpoints completely exposed.
**Learning:** This repo has a scaffolding pattern where `@UseGuards(JwtAuthGuard)` is often commented out by default during initial component creation or is entirely missing, likely for ease of local development, but it was not re-enabled before the code reached production. Additionally, `AuthGuard('jwt')` from `@nestjs/passport` was incorrectly used instead of the custom `JwtAuthGuard` in some places.
**Prevention:** Always verify that authentication guards are correctly imported and active on new and modified controllers. Use the custom `JwtAuthGuard` which supports the `@Public()` decorator for selectively bypassing authentication rather than the default `AuthGuard`.
