## 2025-02-12 - Path Traversal in File Upload Methods
**Vulnerability:** Found path traversal vulnerability in `FilesService.uploadSystemFile` and `SiteCaptureService.create` where `file.originalname` and `subfolder` inputs were not sanitized before being utilized to construct file paths and S3 object keys. This could lead to writing to arbitrary files or bypassing storage boundaries.
**Learning:** `file.originalname` should always be treated as untrusted user input, even when constructing metadata or S3 keys, and must be consistently sanitized. When applying a fix for path traversal vulnerabilities, it must be comprehensive across all methods inside the class dealing with file uploads (like both `upload` and `uploadSystemFile` in `FilesService`). Node.js core modules like `fs` and `path` should be imported correctly using ES6 `import * as path from 'path';` at the top of the file rather than inline `require` statements.
**Prevention:** Always validate and sanitize user-provided file names using `path.basename` and optionally strip illegal characters using regex, and validate parameters like `subfolder` paths before constructing absolute paths.
