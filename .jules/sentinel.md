## 2024-06-13 - Prevent Path Traversal in File Uploads
**Vulnerability:** The \`FilesService.uploadSystemFile\` method used untrusted \`file.originalname\` directly in S3 keys and local file paths, and didn't validate the \`subfolder\` parameter. This allowed attackers to perform path traversal (e.g., using \`../\`) to save files to arbitrary directories or overwrite other S3 objects.
**Learning:** Even if the filesystem isn't local (e.g., using S3), path traversal characters in object keys can still lead to unauthorized overwriting of objects or bypassing folder boundaries. Prepending a timestamp does NOT mitigate this if directory separators exist in the raw filename.
**Prevention:** Always sanitize user-provided filenames using \`path.basename\` and regex replacement to remove unsafe characters before incorporating them into file paths or S3 object keys. Additionally, strictly validate any subfolder paths using fail-secure methods (e.g., throwing on \`..\` or \`\\0\`).
