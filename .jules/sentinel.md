## 2024-05-24 - [Path Traversal in Node.js File Uploads]
**Vulnerability:** Untrusted user input (`file.originalname` and `subfolder`) was used directly in S3 keys and local file system paths via string interpolation and `path.join()`. Prepending a UUID or timestamp does NOT prevent directory traversal if the original filename contains directory separators (e.g., `../../../etc/passwd`).
**Learning:** Node.js `path.join()` will resolve `..` sequences embedded anywhere in the filename, overriding the intended parent directory. S3 also treats `/` as a directory separator, meaning malicious filenames can write objects outside the intended prefix (e.g., `uploads/123-../../../malicious.txt` -> `malicious.txt`).
**Prevention:** Always extract the base filename using `path.basename(file.originalname)` to strip all directory components. Furthermore, strip all remaining illegal characters using a regex like `.replace(/[^a-zA-Z0-9.\-_]/g, '_')`. For user-provided directories (`subfolder`), strictly validate them by stripping null bytes, backslashes, and `../` sequences before using them in `path.join` or S3 `Key` construction.
