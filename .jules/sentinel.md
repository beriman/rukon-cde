## 2025-05-15 - [Authentication Bypass via Missing Server-Side OAuth Token Validation]
**Vulnerability:** The `/auth/google-sync` endpoint in `apps/api` previously trusted the `email` and `name` sent from the client without verifying the origin or authenticity of the session, allowing an attacker to bypass authentication by providing an arbitrary email address. Furthermore, without verifying the `aud` (audience) of the token, the application was vulnerable to Confused Deputy attacks.
**Learning:** Client-side OAuth tokens and sessions cannot be implicitly trusted by backend services. The backend must independently verify the OAuth token with the provider's token info endpoint to ensure the token is valid, matches the provided email, and was issued specifically for the application's client ID.
**Prevention:** Always require and validate the `providerToken` server-side when syncing OAuth users. Use the provider's token info endpoint to verify the `email`, `email_verified` status, and `aud` (audience) against the application's configuration before issuing application-specific JWTs.
