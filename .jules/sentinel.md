## 2026-06-28 - [Path Traversal in File Uploads]
**Vulnerability:** Found Path Traversal and Arbitrary File Overwrite vulnerabilities where user-controlled `file.originalname` and `subfolder` inputs were directly concatenated into file paths (local fs and S3 keys) without sanitization in `FilesService` and `SiteCaptureService`. This could allow attackers to manipulate the intended storage path via directory separators (e.g., `../`), potentially overwriting arbitrary server files or bypassing S3 object boundaries.
**Learning:** Developers often forget that `file.originalname` provided by libraries like Multer is completely untrusted user input, not a safe property generated by the system.
**Prevention:** Always extract just the base filename using `path.basename()` and further sanitize it using a regex (e.g., replacing non-alphanumeric characters) before using it in file operations or S3 keys. Reject explicit path traversal characters like `..` or `\0` in subdirectory parameters.
