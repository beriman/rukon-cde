## 2025-02-14 - Prevent Path Traversal in Uploads via file.originalname
**Vulnerability:** When a file is uploaded, an attacker can manipulate the `file.originalname` field (e.g. `../../etc/passwd`) to execute path traversal. In instances where `file.originalname` is directly appended to directory paths or used to construct S3 keys, this vulnerability could permit overwriting arbitrary system files or bypassing the intended remote object hierarchy boundaries.
**Learning:** `file.originalname` shouldn't be trusted as safe, even when prepended with unique identifiers like timestamps or UUIDs. Functions like `path.join` natively resolve the `..` tokens resulting in directory traversal.
**Prevention:** Always explicitly sanitize untrusted file names in file upload handlers by employing methods such as `path.basename(file.originalname).replace(/[^a-zA-Z0-9.\-_]/g, '_')` immediately upon receiving the file object. Assigning the sanitized string directly to `file.originalname` allows all subsequent logic using it to benefit from the fix safely.
