## 2024-05-15 - [Path Traversal & S3 Key Manipulation]
**Vulnerability:** Path traversal and S3 key manipulation vulnerabilities existed in file upload services (`FilesService` and `SiteCaptureService`). The `file.originalname` field from uploaded files was used directly in constructing S3 object keys and local file paths without any sanitization. Additionally, a user-controlled `subfolder` variable wasn't verified to prevent directory traversal (`..` or null bytes).
**Learning:** Never trust `file.originalname` as it comes directly from user input. Without sanitization, it could include directory navigation sequences (like `../`) which, when used in `path.join()`, can write files outside the intended directories (in local filesystem fallback) or create irregular keys in S3.
**Prevention:** Always use `path.basename(file.originalname)` combined with regex to replace unsafe characters (e.g., `/[^a-zA-Z0-9.\-_]/g`) before appending it to file paths or S3 keys. Also, validate subfolders against `..` and null bytes.
