## 2024-05-19 - [Path Traversal in File Uploads]
**Vulnerability:** Path traversal vulnerability in `files.service.ts` and `site-capture.service.ts` where un-sanitized `file.originalname` and user-controlled `subfolder` strings were used to construct S3 keys and local file paths. This could allow an attacker to read, overwrite, or delete arbitrary files, or traverse S3 buckets.
**Learning:** `file.originalname` in Express/Multer is completely user-controlled and untrusted. Appending it directly to a path or S3 key, even when prefixed with timestamps or UUIDs, does not prevent directory traversal if the original name contains `../` or `/` sequences. Additionally, subfolder arguments must be sanitized.
**Prevention:** Always sanitize `file.originalname` using `path.basename()` followed by a regex filter to remove or replace unsafe characters (e.g., `/[^a-zA-Z0-9.\-_]/g`). Sanitize subfolders by removing `../`, backslashes, and null bytes before use in path construction.
