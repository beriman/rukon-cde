## 2024-10-24 - File Upload Path Traversal via Untrusted Filenames and Subfolders
**Vulnerability:** Methods generating file paths and S3 keys using `file.originalname` directly (e.g. `upload` and `uploadSystemFile` in `files.service.ts`, `create` in `site-capture.service.ts`) without sufficient sanitization. Additionally, `subfolder` parameters were used in path construction without boundary checking.
**Learning:** In Node.js, prepending a string (like a timestamp or UUID) to an unsanitized filename does not mitigate path traversal vulnerabilities, especially when it goes through `path.join()` or when special characters inject malicious intent into storage system paths and metadata. Using a strict "fail secure" logic on paths combined with explicit extraction rules is key.
**Prevention:** Always validate directory structures like `subfolder` explicitly to reject dangerous strings (e.g., `..` and `\0`). For filenames, always extract the raw name using `path.basename()` and further strip or replace any unsafe characters using regex (e.g., `.replace(/[^a-zA-Z0-9.\-_]/g, '_')`) before using it in local file paths, S3 keys, S3 metadata, or database schemas.
