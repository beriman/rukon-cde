## 2026-04-08 - Path Traversal in File Uploads\n**Vulnerability:** Path Traversal vulnerability in `uploadSystemFile` (files.service.ts) and `create` (site-capture.service.ts) where `file.originalname` and `subfolder` inputs were passed without sanitization into `path.join` and S3 key string interpolations.\n**Learning:** Relying on the user-controlled `originalname` from file uploads can lead to arbitrary file writes or reads (Path Traversal) if not properly stripped of path separation sequences like `../`.\n**Prevention:** Always use `path.basename` to extract only the filename and further strip any non-safe characters using a strict regex (e.g., `/[^a-zA-Z0-9.\-_]/g`) before using file names in file system paths or S3 object keys. Verify directory/folder path arguments strictly against alphanumeric regexes.
