## 2024-05-24 - [Missing Authentication Guards on API Controllers]
**Vulnerability:** Several controllers within `apps/api/src/construction` were completely exposed without any authentication requirements. Specifically, `@UseGuards(JwtAuthGuard)` was either commented out or completely missing from `claim.controller.ts`, `procurement.controller.ts`, `construction.controller.ts`, and `submittal.controller.ts`. `correspondence.controller.ts` had a mix of commented out default guards and default ones.
**Learning:** This architectural flaw frequently occurs during rapid scaffolding or debugging where guards are temporarily bypassed but mistakenly left disabled before commit. It exposes sensitive endpoints to unauthorized access, allowing unauthenticated users to create claims, manage procurement items, and interact with the construction module directly.
**Prevention:** We must enforce a strict policy where all newly created controllers include `@UseGuards(JwtAuthGuard)` by default, leveraging `@Public()` decorators explicitly for endpoints that intentionally require public access. We must implement automated linting rules or pre-commit hooks to flag controllers lacking global or class-level authentication decorators.
