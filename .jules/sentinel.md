## 2024-08-05 - Path Traversal via Unsanitized Filenames in S3/Local Uploads
**Vulnerability:** Path traversal vulnerabilities were found in file upload endpoints (`FilesService` and `SiteCaptureService`) because `file.originalname` was passed unsanitized to `path.join()` or S3 object key constructors, allowing bypass of the directory structure. Prepending UUIDs or timestamps does not prevent path traversal if `path.join()` resolves `..` segments.
**Learning:** In Node.js, prepending a string (like UUID or timestamp) to a user-provided filename does not prevent path traversal if the original filename contains directory separators and is processed by `path.join()`. Always sanitize the raw input using `path.basename()` before appending or manipulating it.
**Prevention:** Always sanitize user-provided filenames immediately at the start of upload functions using `path.basename(file.originalname).replace(/[^a-zA-Z0-9.\-_]/g, '_')` before using them in file system paths or S3 object keys. Validate any other path parameters (like `subfolder`) to reject `..` and `\0`.
