# Epic 4: Construction Monitoring Suite

**Goal**: Comprehensive dashboard tools for Contractors to monitor execution (Field Execution).

## Stories

### Technical Monitoring
- [ ] **Story 4.1: Technical Monitoring Dashboard**
  - **Goal**: Track progress and technical issues for Structure, Architecture, and MEP disciplines.
  - **Features**: Discipline specific dashboards, Issue aggregation, Progress bars.

### Document Control
- [ ] **Story 4.2: Shop Drawings & Method Statements**
  - **Goal**: Manage the submission and approval flow of Shop Drawings and Method Statements.
  - **Features**: Status tracking (Submitted, Reviewed, Approved, RFI), Approval workflows.
- [ ] **Story 4.3: Material Approvals**
  - **Goal**: Manage material sample and specification approvals.
  - **Features**: Digital submittal log, Material specs comparison, Approval history.

### Commercial & Procurement
- [ ] **Story 4.4: Procurement & BQ Monitoring**
  - **Goal**: Track procurement of long lead items and Bill of Quantities usage.
  - **Features**: Long lead item tracking, BQ usage vs actuals.
- [ ] **Story 4.5: Payment & Billing**
  - **Goal**: Monitor financial progress including claims, variations, and invoices.
  - **Features**: Progress Claim tracking, Variation Order (VO) logs, Invoicing status.

### Project Control
- [ ] **Story 4.6: Project Concrol Dashboard (S-Curve)**
  - **Goal**: Visualize project progress against time and cost.
  - **Features**: S-Curve generation (Planned vs Actual), Real-time progress visualization.
  - **Note**: Depends on data from other stories.

### Data Compliance
- [ ] **Story 4.7: COBie & Data Compliance**
  - **Goal**: Ensure asset data quality and COBie compliance.
  - **Features**: COBie Health Check dashboard, Parameter validation alerts.

### Correspondence
- [ ] **Story 4.8: Correspondence Log**
  - **Goal**: Centralize communication between MK/Owner and Contractor.
  - **Features**: Site Memos log, Instruction Letters (SI) log.
