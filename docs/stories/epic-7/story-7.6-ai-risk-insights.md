# Story 7.6: AI Risk Insights (Predictive Analysis)

**Epic**: Epic 7 - Mobile AI Assistant  
**Story ID**: `story-7.6`  
**Story Points**: 8  
**Priority**: P1 (High)  
**Sprint**: Sprint 24 (Weeks 47-48)

## User Story

**As a** Project Director,  
**I want to** receive proactive alerts about potential project risks,  
**So that** I can mitigate them before they cause delays.

## Acceptance Criteria

### Functional
- [ ] **Analysis**: AI analyzes Schedule (Epic 6), Issues (Epic 6), and Weather data
- [ ] **Insights**: Identify risks like "Concrete pouring scheduled during heavy rain" or "High number of open issues in Zone A"
- [ ] **Recommendations**: Suggest mitigation actions
- [ ] **Indonesian Context**: Weather data source (BMKG)

## Technical Tasks

### Backend
- [ ] Implement Risk Analysis Agent (Scheduled Job)
- [ ] Integration with Weather API

## Dependencies
- **Depends on**: Epic 6 (Schedule/Issues)
