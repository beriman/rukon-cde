# Story 8.10: HazMat Mapping

**Epic**: Epic 8 - Security, Compliance & Lifecycle  
**Story ID**: `story-8.10`  
**Story Points**: 5  
**Priority**: P2 (Medium)  
**Sprint**: Sprint 29 (Weeks 57-58)

## User Story

**As a** Deconstruction Planner,  
**I want to** identify elements containing hazardous materials,  
**So that** removal is planned safely.

## Acceptance Criteria

### Functional
- [ ] **Tagging**: Tag elements (Asbestos, Lead Paint, PCB)
- [ ] **Layer Toggle**: HazMat layer can be toggled in 3D Viewer
- [ ] **MSDS**: Link Material Safety Data Sheets to elements
- [ ] **Removal Plan**: Sequence removal with safety protocols

## Technical Tasks

### Frontend
- [ ] Implement HazMat layer in 3D Viewer

## Dependencies
- **Depends on**: Epic 6 (3D Viewer)
