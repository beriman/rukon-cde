# Story 8.11: Material Passport (Circular Economy)

**Epic**: Epic 8 - Security, Compliance & Lifecycle  
**Story ID**: `story-8.11`  
**Story Points**: 8  
**Priority**: P2 (Medium)  
**Sprint**: Sprint 29 (Weeks 57-58)

## User Story

**As a** Sustainability Manager,  
**I want to** track material recyclability and salvage value,  
**So that** deconstruction is economically viable.

## Acceptance Criteria

### Functional
- [ ] **Metadata**: Material Type, Recyclability %, Salvage Value per element
- [ ] **Search**: Filter elements by recyclability
- [ ] **Inventory**: Generate Material Inventory report
- [ ] **Export**: Export to Madaster platform (optional)

## Technical Tasks

### Backend
- [ ] Add material properties to IFC element metadata

## Dependencies
- **Depends on**: Epic 6 (IFC Viewer)
