# Story 8.5: Asset Twin (AIM)

**Epic**: Epic 8: Security, Compliance & Asset Lifecycle
**Status**: Done
**Priority**: High
**Estimation**: 8 Points

## User Story
**As a** Facility Manager,
**I want to** maintain a live Asset Information Model,
**So that** I can track all building assets throughout their lifecycle.

## Acceptance Criteria
- [x] Import PIM to AIM at handover
- [x] AIM includes: As-built drawings, O&M manuals, Warranty docs
- [x] Live data integration ready (IoT, BMS)
- [x] Asset register with location, specs, maintenance history

## Technical Tasks
- [x] **Backend**: AssetService with CRUD
- [x] **Backend**: Bulk import from PIM
- [x] **Backend**: Query and search functionality
