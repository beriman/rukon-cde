# Story 8.6: Maintenance Scheduler

**Epic**: Epic 8: Security, Compliance & Asset Lifecycle
**Status**: Done
**Priority**: Medium
**Estimation**: 5 Points

## User Story
**As a** Maintenance Coordinator,
**I want to** schedule and track maintenance tasks,
**So that** assets are properly maintained and compliant.

## Acceptance Criteria
- [x] Define maintenance tasks per asset type
- [x] Auto-generate work orders based on schedule
- [x] Trigger events: Time-based, condition-based, breakdown
- [x] Track completion with technician sign-off

## Technical Tasks
- [x] **Backend**: MaintenanceService with scheduling
- [x] **Backend**: Work order generation
- [x] **Backend**: Task completion with next-due calculation
