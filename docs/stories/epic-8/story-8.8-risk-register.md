# Story 8.8: Risk Register (ISO 19650-6)

**Epic**: Epic 8: Security, Compliance & Asset Lifecycle
**Status**: Done
**Priority**: Medium
**Estimation**: 5 Points

## User Story
**As a** Safety Manager,
**I want to** maintain a risk register linked to 3D locations,
**So that** risks are visible in context during site work.

## Acceptance Criteria
- [x] Database of risks with severity ratings
- [x] Risks linked to 3D model locations
- [x] Risk categories: Safety, Schedule, Cost, Quality
- [x] Mitigation measures tracked

## Technical Tasks
- [x] **Backend**: RiskRegisterService with scoring
- [x] **Backend**: Location linking for 3D
- [x] **Backend**: Risk matrix generation
