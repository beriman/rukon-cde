# Story 8.9: Visual Safety Tagging (3D)

**Epic**: Epic 8 - Security, Compliance & Lifecycle  
**Story ID**: `story-8.9`  
**Story Points**: 5  
**Priority**: P2 (Medium)  
**Sprint**: Sprint 29 (Weeks 57-58)

## User Story

**As a** HSE Officer,  
**I want to** tag hazardous areas in the 3D model,  
**So that** workers are aware of risks.

## Acceptance Criteria

### Functional
- [ ] **Tagging**: Tag zones (Fall Risk, Overhead Load, Confined Space)
- [ ] **Visualization**: Red zones, Warning icons in 3D Viewer
- [ ] **Info**: Hover to show safety information
- [ ] **Export**: Export safety plan PDF with tagged model

## Technical Tasks

### Frontend
- [ ] Implement safety overlay layer in 3D Viewer

## Dependencies
- **Depends on**: Epic 6 (3D Viewer)
