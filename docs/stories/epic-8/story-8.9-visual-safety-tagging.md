# Story 8.9: Visual Safety Tagging

**Epic**: Epic 8: Security, Compliance & Asset Lifecycle
**Status**: Done
**Priority**: Medium
**Estimation**: 3 Points

## User Story
**As a** HSE Coordinator,
**I want to** tag hazardous areas in the 3D viewer,
**So that** workers can identify dangers before entering areas.

## Acceptance Criteria
- [x] Tag hazardous areas (Fall risk, Overhead load, etc.)
- [x] Visual indicators: Red zones, Warning icons
- [x] Safety information displayed on hover
- [x] Export safety plan with tagged model
