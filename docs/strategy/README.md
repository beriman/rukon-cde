# Ruang Konstruksi — Strategy Index

Ruang Konstruksi adalah **AI-first Construction Operating System** dengan CDE sebagai fondasi informasi proyek.

## Prinsip Produk

- **CDE** = source of truth proyek
- **Dashboard** = command center
- **Text / Voice** = natural control interface
- **AI Agents** = intelligent workers
- **Engineering Workers** = deterministic execution layer
- **Human Approval** = authority / final decision

## Fokus Saat Ini

Target pertama adalah **kontraktor**. Workspace konsultan perencana direncanakan sebagai fase lanjutan dengan workflow berbeda.

MVP harus membuktikan tiga hal:
1. dokumen proyek dapat dipercaya sebagai versi yang sah,
2. drawing/model dapat diakses nyaman dari desktop dan mobile,
3. AI dapat menjelaskan status dan menjalankan aksi terkontrol tanpa melewati authority manusia.
